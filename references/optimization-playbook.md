# 找不到资源 / 下载慢 — 优化手册（进阶）

> 两个最高频痛点的完整解决方案，按性价比排序。

## 一、找不到资源

按顺序尝试，每一步都比下一步便宜：

### 1. 换搜索姿势（零成本，最常见原因）
- **换关键词语言**：中文片名搜不到 → 用英文原名 + 年份（`Inception 2010 REMUX`）；冷门外语片 → 用原名
- **换发布组术语**：搜 `2160p REMUX` 比 `4K 蓝光原盘` 命中率高；老片加 `BluRay` 不加 `UHD`
- **聚合搜索**：TPB/1337x 之外加 `bt4g.org`（DHT 索引，覆盖极广）、`btsow`、`torrend.to` 聚合器
- **电视剧**：搜整季包 `S01 1080p` 比单集快，也常有 REMUX

### 2. 换资源类型
REMUX 没有时的降级链（画质递减但通常都有货）：
`4K REMUX → 4K BDRip(x265) → 1080p REMUX → 1080p WEB-DL → 1080p x264`
- WEB-DL 有"假4K"陷阱：标 2160p 但码率 <20Mbps，ffprobe 一验便知
- 冷门老片：可能只有 DVD 480p，认命

### 3. 换获取通道
- **网盘离线**（国内最快）：115/夸克离线秒完成，搜网盘资源站或 TG 频道（如"4K影视屋"）拿分享链。115 付费但离线+大文件最稳
- **PT 站**（长期最优）：申请一个 PT 站（如某些开放注册的影视站），新片几小时就有高做种 REMUX，速度拉满带宽。门槛=考核期，值得投入
- **求助补种**：PT 站发求种帖

### 4. 实在找不到
- 豆瓣/IMDb 确认片名拼写和上映年份（名字相似的片子极多）
- 确认有没有出过蓝光/4K 盘（有些电影只有流媒体版，那就只有 WEB-DL）

## 二、下载速度慢

### 0. 先诊断（30 秒）
看 aria2 日志 `CN:x SD:y`：
- **SD=0**（无做种）：资源本身没速度，换版本或换通道，别等
- **CN 低 SD 正常**：连接数上不去 → 网络问题，往下看 2
- **CN/SD 都正常但速度低**：单 peer 限速或跨网拥堵 → 等 BT 马太效应或加 tracker

### 1. 补 tracker（最有效，实测 0→39 连接）
磁力链自带 tracker 少是常态。RPC 补一轮 tracker 池（见 nas-media-download.md），90 秒内见效。更好的做法：启动时直接带上 10+ tracker（池已写在部署文档）。

### 2. 开 IPv6 直连
**你家已有公网 IPv6**——这是最大杀器。NAS 的 aria2 已监听 IPv6，但路由器防火墙可能拦了入站：
- 路由器管理页：放行 IPv6 防火墙 26999 端口（TCP/UDP），DHT 26998/UDP
- 效果：别人能主动连上你 → 可连的 peer 池翻倍，冷门资源速度显著提升
- 同理，NAS 的 WebDAV 8688 也是靠 IPv6 才能在外网访问，同一个道理

### 3. 端口映射（IPv4 补充）
如果宽带有公网 IPv4（很多家宽没有）：路由器把 26999 转发到 NAS。没有 IPv4 就靠 IPv6 即可。

### 4. BT 客户端参数（已内置 skill 脚本）
- `--bt-max-peers` 提高到 128（默认 55）
- `--bt-request-peer-speed-limit` 设为带宽的 80%（让 aria2 更积极要数据）
- `--max-connection-per-server=16`

### 5. 换下载引擎（速度瓶颈在引擎时）
- **qBittorrent-nox**：DHT/PEX/LSD 全开，peer 发现比 aria2 强，有 WebUI 手机也能看进度。NAS 上 `apt install qbittorrent-nox`（需 sudo）或用户态二进制
- **迅雷/115 离线**：国内冷门资源有时离线秒下（它们有自家缓存），但 4K REMUX 大文件部分网盘限速

### 6. 时段选择
晚 8-11 点是家用带宽高峰，国内 peer 多但拥堵；凌晨速度快 30-50%。挂机下载无所谓，赶时间可预约凌晨跑。

## 三、决策速查

```
搜不到 → 换英文片名+年份 → 聚合站bt4g → 降级资源类型 → 网盘离线 → PT站
速度慢 → 日志看SD → SD=0换版本 → SD>0补tracker → 开IPv6入站 → 换qbittorrent → 凌晨挂机
```
