# 音乐下载进阶优化（配合 musicdl-core.md）

> musicdl 解决"能下到"，这份解决"下得更好、更快、更全"。按价值排序。

## 一、音质升级路径（musicdl 之上）

musicdl 四源（网易/QQ/酷狗/酷我）的天花板是 **16bit/44.1kHz FLAC**。要更高：

1. **Hi-Res 母带**（24bit/192kHz）
   - 来源：索尼精选/OpenOsu/Apple Music Alac（均付费）；QTDownload 之类的第三方工具随缘
   - 判别：mutagen 读 `bits_per_sample>=24 and sample_rate>48000` 才算真 Hi-Res
   - 注意：网上很多"Hi-Res"是 44.1k 重采样贴标，**必须读流参数验明正身**
2. **BDMV/ISO 抓轨**：演唱会原盘、专辑原盘里提取，音质天花板但来源少，搜 `专辑名 BDMV` 或 `SACD ISO`
3. **黑胶转录/DSD**：小众收藏向，`dsf/dff` 格式，播放器支持有限先确认

## 二、速度优化

1. **musicdl 并发**：默认串行逐源搜，批量任务改造为 `ThreadPoolExecutor` 四源并发搜索（4 倍提速），下载阶段按源分组并行
2. **失败快速跳过**：单候选下载超时 60s 直接放弃换下一个，别死等（实测能省 30% 总时长）
3. **断点续跑兜底**：超长任务（500+ 首）在 NAS 后台挂机跑，中断重跑自动 SKIP 已完成的

## 三、命中率优化（找不到歌/版本不对）

1. **关键词工程**：
   - 加年份：`崔健 一无所有 1986` 挡住翻唱
   - 用专辑名：`花房姑娘 新长征路上的摇滚` 精确定位
   - 冷门歌试拼音/英文艺名
2. **候选排序加权**：`file_size` 最大 ≠ 最好——同码率下时长匹配目标歌长的优先（防串烧/慢速版冒充）
3. **补源清单**：musicdl 之外可用 yt-dlp（YouTube 音轨，冷门现场版/官方高清修复版多）+ 油管转 FLAC 管线，配合 musicdl 双路并行

## 四、元数据与整理（批量任务的最后一公里）

1. **自动补标签**：musicdl 下载的 FLAC 常缺封面/专辑/年份 → 用 mutagen 从 MusicBrainz API 按 `歌名+歌手` 匹配补全，嵌入封面图
2. **命名规范**：`歌手 - 歌名 [专辑, 年份].flac`（比裸 `歌手 - 歌名` 更好检索）
3. **查重**：同歌多版本处理规则——录音室版 > 现场版 > 精选集收录版，按需保留
4. **库索引**：`music_library.json`（同电影库格式），下载前查重避免重复劳动

## 五、通知与自动化

- 批量任务完成 → QQ 推送汇总（成功 X 失败 Y 缺 Z，失败原因列表）
- NAS crontab 定时清理 pkl/空目录
- 失败歌单自动存 `retry_list.txt`，隔周源库更新后一键重试

## 六、已知限制（诚实清单）

- 华语老歌版权黑洞客观存在（崔健《一无所有》级别的），重试也救不了
- musicdl 依赖第三方接口，接口变更会突然全挂——社区更新慢，必要时换 `yt-dlp` 作为备用引擎
- 翻唱过滤是概率战：黑名单挡 90%，剩下 10% 靠元数据校验兜底，仍可能漏网 1-2%
